# Test ROM sources

Every file in this folder must be **freely redistributable**. Record each one below before committing it
(SPEC §11.3). If a suite's license is unclear, don't commit it. Instead, have CI download it from its
official source at test time.

**Never commit commercial ROMs, BIOS files, or dumps of licensed games, even "for testing."**
To test against your own dumps, set `GAMEVAULT_LOCAL_ROMS` to a local folder. Tests marked
`[LocalRomFact]` run only when it is set.
