# Sources of codes

## Codes from GameGenie.com

**Codes → "Get codes from GameGenie.com"** shows codes that come from
[GameGenie.com](https://gamegenie.com/cheats/gamegenie/nes/index.html) (© Danworld, Inc.).
- GameVault downloads a game's page from the site only when the player asks.
- Wherever the codes appear, they are shown with that credit and a link to the game's page.
- The codes are not stored in this repository and are not part of GameVault.

## Code collections players import

Players can import their own code lists in **Settings → Codes** (.xlsx or .csv with Game, Code and Effect
columns), for example a compilation of the official Game Genie codebook. Like ROMs and the Disk System
BIOS, these files come from the player and stay in their own app folder. Codes from a collection are shown
with the collection's name and the source its rows give.
