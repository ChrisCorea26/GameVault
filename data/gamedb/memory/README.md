# Memory maps

One JSON file per game, keyed by headerless SHA-1. The format is documented in
[`docs/memory-maps.md`](../../../docs/memory-maps.md). The maps here (Super Mario Bros., The Legend of Zelda and
Metroid) come from public disassemblies; [`docs/gamedb-sources.md`](../../../docs/gamedb-sources.md) cites each
address, and the owner checklist in `docs/plans/phase-9.md` has them checked against real copies.
