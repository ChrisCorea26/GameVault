# Edition history

| Edition | Date | Changes |
|---|---|---|
| 1 | October 2026 | First edition. Covers NES and Famicom Disk System, SG-1000 and Master System, Apple II, Genesis / Mega Drive, Super Nintendo, PlayStation and Nintendo 64. |
| 2 | October 2026 | Adds the PlayStation 2: its section in Supported systems, the DualShock 2's controls (both sticks, L3 and R3), Settings → PlayStation 2, `.ps2` memory cards, and its limits on rewind, run-ahead and netplay. |
| 3 | October 2026 | Remapping buttons (per system, player, controller model and game; one-handed keyboard layouts), the Player's Controllers flyout and Players 3–4, the Power Pad and Arkanoid paddle, the bundled homebrew games, accessory profiles, memory maps and Metroid's password definition, per-system Game Details properties and details for unknown games, confirmations before deleting, Choose… buttons for BIOS files, saves next to the game files, the Hide screen edges amount, the rewind scrub bar, and the Disk II boot ROM message. |
| 4 | October 2026 | A BIOS chosen with **Choose…** is copied into GameVault's own `bios` folder. The PlayStation 2 runs much faster (its main processor's code is translated as it runs, and its graphics are drawn on several cores), and the Nintendo 64's graphics are drawn on several cores too. |
| 5 | October 2026 | Every page and menu can be used with a controller alone: the D-pad moves between items, the bottom button presses, flips or opens them, the top button opens an item's menu, the shoulders switch between Library and Settings, and the triggers jump a screen up or down a long page. |
