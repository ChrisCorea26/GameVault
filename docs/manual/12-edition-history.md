# Edition history

| Edition | Date | Changes |
|---|---|---|
| 1 | October 2026 | First edition. Covers NES and Famicom Disk System, SG-1000 and Master System, Apple II, Genesis / Mega Drive, Super Nintendo, PlayStation and Nintendo 64. |
| 2 | October 2026 | Adds the PlayStation 2: its section in Supported systems, the DualShock 2's controls (both sticks, L3 and R3), Settings → PlayStation 2, `.ps2` memory cards, and its limits on rewind, run-ahead and netplay. |
| 3 | October 2026 | **Browse…** buttons for every file path in Settings, and **Choose BIOS file…**, which copies your BIOS into GameVault's own folder. The PlayStation 2 runs much faster (its main processor's code is translated as it runs, and its graphics are drawn on several cores), and the Nintendo 64's graphics are drawn on several cores too. |
