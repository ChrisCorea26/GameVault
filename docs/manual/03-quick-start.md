# Quick start

You can be playing within a minute, without opening Settings.

1. **Start GameVault.** The Library opens with four homebrew games that come with GameVault (see
   [Bundled homebrew](#bundled-homebrew)). You can play one of those straight away.
2. **Choose Add a ROM folder** and pick the folder where you keep your games. GameVault searches it and every
   folder inside it, and lists every game it finds.
3. **Click a game**, then **Play**. Or right-click its tile and choose **Play**.
4. **Play** with the keyboard (arrow keys, <kbd>Z</kbd> = B, <kbd>X</kbd> = A, <kbd>Enter</kbd> = Start,
   <kbd>Right Shift</kbd> = Select) or plug in a controller. It's set up automatically.
5. **Press <kbd>Esc</kbd>** to pause. **Back to library** saves where you are, and next time GameVault offers to
   resume.

To play a single file without adding its folder, choose **Open game file**.

## Next steps

- **Name your games and see a complete checklist** by importing a catalog. See
  [Importing a catalog](#importing-a-catalog).
- **Set up BIOS files** if you play Famicom Disk System, Apple II, PlayStation or PlayStation 2 games. See
  [Supported systems](#supported-systems).
- **Learn the hotkeys**: <kbd>F5</kbd> save state, <kbd>F8</kbd> load it, hold <kbd>Backspace</kbd> to rewind, hold
  <kbd>Tab</kbd> to fast-forward, <kbd>F11</kbd> full screen. See [Hotkeys](#hotkeys).
- **Mark what you own** and track your progress in Game Details.

## The screens

| Screen | How to get there | What it's for |
|---|---|---|
| **Library** | Navigation pane, or <kbd>Alt</kbd>+<kbd>L</kbd> | Your games and the complete checklist |
| **Game Details** | Click a game | Collection status, notes, save states, passwords, journal, codes, per-game properties |
| **Player** | **Play** | The game itself, with save states, assist, practice, netplay and more |
| **Settings** | The gear in the navigation pane | Folders, video, audio, controllers, BIOS files, family profiles, RetroAchievements |
| **Import a catalog** | Library → **Import catalog** | Adds a list of known releases |
| **Dump a cartridge** | Library → **Dump cartridge** | Dumps an NES cartridge with an INL Retro-Prog |
